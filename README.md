# برق المعدات الحديثة | Barq Modern Equipment

**الموقع الرسمي لشركة [برق المعدات الحديثة](https://barqk.com/)، لتأجير معدات الرفع والمعدات الثقيلة في الرياض.** تؤجّر الشركة السيزر ليفت والمان ليفت والرافعات الشوكية والبوبكات والشيولات والحفارات والكرينات والمولدات، وتبيع معدات جديدة ومستعملة.

هذا المشروع موقع عربي من اليمين لليسار مبني بـ Laravel، فيه كتالوج معدات بمقاسات وارتفاعات محددة، ولوحة تحكم يدير منها فريق الشركة المعدات والطلبات والمحتوى والتقييمات.

🌐 **الموقع:** [barqk.com](https://barqk.com/)

## ماذا يحتوي المشروع؟ | What's inside

<div dir="rtl">

### للزائر (الواجهة العامة)
- **كتالوج معدات بمستويين:** صفحة لكل فئة (سيزر ليفت، مان ليفت، فوركلفت، كرينات، مولدات…)، وتحتها صفحات لكل مقاس، مثل سيزر ليفت كهربائي 6 أو 8 أو 10 أمتار، أو ديزل 16 إلى 18 متراً.
- **قسم للبيع** للمعدات الجديدة والمستعملة.
- صفحات خدمات، وصفحة للرياض، وعروض، ومدونة.
- **نموذج طلب عرض سعر** يصل إلى لوحة التحكم، وتقييمات عملاء.

### لفريق الشركة (لوحة التحكم)
- لوحة تحكم مكتوبة خصيصاً للمشروع لإدارة: المعدات وفئاتها، والخدمات، والصفحات، والمقالات، والعروض، والمشاريع، والعملاء، والأحياء، والوسائط، والتحويلات (Redirects)، والروابط الداخلية، والإعدادات.
- **ربط مع تقييمات Google:** مزامنة تقييمات النشاط التجاري والرد عليها من داخل اللوحة.
- إدارة طلبات عروض الأسعار، وأدوات سيو، وسجل نشاطات.
- معالجة الصور وضغطها عند الرفع (Intervention Image).

### السيو المحلي
- خريطة موقع XML تتولد من المحتوى، وملفا `robots.txt` و`llms.txt`.
- بيانات منظمة (JSON-LD) للنشاط التجاري المحلي وساعات العمل والموقع الجغرافي والأسئلة الشائعة.

</div>
